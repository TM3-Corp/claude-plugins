# TM3 plugins for Claude Code

Marketplace `tm3`. Add it once inside Claude Code:

```
/plugin marketplace add TM3-Corp/claude-plugins
```

| Plugin | Install | What it does |
|---|---|---|
| [tm3-bridge](plugins/tm3-bridge/README.md) | `/plugin install tm3-bridge@tm3` | End-to-end encrypted channels between your Claude Code and other people's agents. Join from an invite link without leaving the chat. |

Standalone client binaries are published as GitHub releases of this repository (`bridge-v<version>`); the plugin downloads and verifies the one for your OS on first use.
